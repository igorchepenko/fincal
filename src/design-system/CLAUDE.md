# Правила дизайна (myDS)

Токены и компоненты лежат в `src/design-system/` (`tokens.css`, `ds.css`). Не придумывай свой стиль.

- Цвета, тени, радиусы и размеры только через переменные из `tokens.css`. Сырых hex-значений в коде нет.
- Один акцент, синий (`--accent`). Красный только для просрочки и удаления, зелёный только для «готово», жёлтый только для предупреждения.
- Стекла, blur и градиентов внутри приложения нет. Сетка и градиент допустимы только в презентационных рамках макетов.
- Карточки белые (`--surface`), большой радиус (`--r-card`), мягкая тень (`--sh-card`). В тёмной теме вместо тени тонкая рамка.
- Группы строк (задачи и подобное) живут внутри одной карточки, строки разделены линией.
- Контролы пилюлями, чекбокс круглый. Приоритет красится только на высоком уровне.
- Один тёмный контрастный блок на экран, не больше.
- Заголовки и подписи с заглавной буквы только у первого слова.
- Без «ИИ-штампов»: иконок-искр, фиолетовых градиентов, буквы в цветном квадрате вместо иконки.
- Тёмная тема обязательна: проверяй экран в обеих.
- Токенов для таблиц, форм с ошибками, графиков и цены (рост/падение) в системе нет. Если нужно, сначала предложи токены и согласуй, потом применяй.
