# Правила дизайна (myDS)

Токены и компоненты лежат в `src/design-system/` (`tokens.css`, `ds.css`). Не придумывай свой стиль.

- Цвета, тени, радиусы и размеры только через переменные из `tokens.css`. Сырых hex-значений в коде нет.
- Один акцент, синий (`--accent`). Красный только для просрочки, удаления и ошибок ввода в поле, зелёный только для «готово», жёлтый только для предупреждения.
- Деньги: приход зелёный, расход красный, но только через `--income*` и `--expense*` и только для сумм, значков и линий графика. Знак (+ или −) пишется всегда, цвет его только усиливает. Статус платежа красится по-старому: «выполнен» `--success`, «просрочен» `--danger`. Не смешивай эти пары.
- Стекла, blur и градиентов внутри приложения нет. Сетка и градиент допустимы только в презентационных рамках макетов.
- Карточки белые (`--surface`), большой радиус (`--r-card`), мягкая тень (`--sh-card`). В тёмной теме вместо тени тонкая рамка.
- Группы строк (задачи и подобное) живут внутри одной карточки, строки разделены линией.
- Контролы пилюлями, чекбокс круглый. Приоритет красится только на высоком уровне.
- Один тёмный контрастный блок на экран, не больше. Подсказка на графике рисуется нейтральной (`--raised`) и тёмным блоком не считается.
- Заголовки и подписи с заглавной буквы только у первого слова.
- Без «ИИ-штампов»: иконок-искр, фиолетовых градиентов, буквы в цветном квадрате вместо иконки.
- Тёмная тема обязательна: проверяй экран в обеих.
- Для графика, календаря, таблицы и полей есть токены-алиасы (`--chart-*`, `--cal-*`, `--tbl-*`, `--field-*`), для денег `--income*`/`--expense*`. Бери их, не мешай со статусными. Если нужен новый смысл цвета, сначала предложи токен и согласуй, потом применяй.
- Число в таблицах, календаре и строках платежей: моноширинный шрифт (`.mono` или `.amt`), выравнивание вправо.
- Всё, что открывается поверх экрана (диалог, меню, выбор даты, поповер, мастер): карточка `--raised`, тень `--sh-float`, без blur. Затемнение под диалогом: `--scrim`.
- Красная кнопка (`.btn.danger`) только у удаления. Предупреждения (минус на остатке, порог, бюджет от 85%, копия устарела) жёлтые. Баннер (`.ban`): жёлтый предупреждение, синий «нужно проверить», красный ошибка, зелёный «готово».
- Выбор строк синий (`.cb.pick`), зелёный круг только «выполнено». Панель массовых действий на `--raised`, не тёмная. Состояние «нельзя» (например, перенос в прошлое) показывать приглушением, не красным.
- Вкладки (`.tabs`) подчёркиванием, пилюля `.seg` только для переключения вида внутри экрана. Счётчик (`.bdg`): красный только для просроченных.
- Положительный остаток нейтральный, красный только у отрицательного. Прогноз и сценарий на графике пунктиром; порог линия и подпись `--warning-text` (сам `--warning` на светлом ниже 3 по контрасту).
- Цвета категорий и счетов только 16 `--sp-*` (teal, berry, clay, slate, cocoa, sage, graphite, rust, violet, olive, navy, mauve, indigo, mustard, plum, sky). Назначай по порядку, соседние в этом порядке различимы. Цвет всегда вместе с названием или значком. Мелкий текст на заливке только белым/`--on-accent` и не на teal и sage (у них контраст ниже 4,5); для них значок или крупный жирный текст. Когда категорий больше 16, остаток сводится в «Остальное». Не используй `--success`, `--danger`, `--warning`, `--income`, `--expense` и `--accent` как цвет категории. Пустое состояние: значок, заголовок, одна фраза, до двух действий, без иллюстраций. Скелетон: `--ink-1`/`--ink-2`, анимация отключается при «уменьшить движение».
