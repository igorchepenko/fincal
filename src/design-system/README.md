# Дизайн-система MyDS

Файлы `tokens.css` и `ds.css` скопированы из личной дизайн-системы MyDS (чистый CSS, без JS).

**Не правь их здесь.** Источник правды — MyDS. Изменения вноси в MyDS и копируй файлы сюда целиком.

- `tokens.css` — токены (цвета, радиусы, размеры, тени). Тёмная тема включается системной настройкой или атрибутом `data-theme="dark"` на `<html>`.
- `ds.css` — классы компонентов (`.btn`, `.card`, `.chip`, `.seg`, `.sw`, `.nav`, `.toast` и др.). Свои цвета не задаёт, работает поверх токенов.

Подключаются первыми импортами в `src/main.tsx`: сначала `tokens.css`, затем `ds.css`.
